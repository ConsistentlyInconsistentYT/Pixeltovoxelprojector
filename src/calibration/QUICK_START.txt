USAGE EXAMPLES
--------------

Python Calibration:
-------------------
from calibration import CameraCalibrator
import cv2

calibrator = CameraCalibrator(camera_id=0)
calibrator.pattern.pattern_type = "checkerboard"
calibrator.pattern.rows = 9
calibrator.pattern.cols = 6

# Add calibration images
for img_path in glob.glob("calib/*.jpg"):
    img = cv2.imread(img_path)
    calibrator.add_calibration_image(img)

# Calibrate
result = calibrator.calibrate_intrinsics()
print(f"RMS Error: {result.rms_error:.4f} pixels")

# Save
calibrator.save_calibration("camera.json")

CALIBRATION WORKFLOW
--------------------

1. Capture 20-30 images of checkerboard pattern
   - Various distances and orientations
   - Good lighting, sharp focus

2. Run intrinsic calibration:
   python3 calibrate_intrinsics.py --images "calib/*.jpg"

3. Verify RMS error < 0.5 pixels

4. For stereo: Capture synchronized pairs and run stereo calibration

5. For multi-camera: Run bundle adjustment with shared observations
